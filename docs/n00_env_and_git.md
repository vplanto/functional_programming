## 1. Встановлення Java (JDK 21+) та Scala

Сучасна екосистема Scala використовує інструмент **Coursier** (`cs`) для керування залежностями, компіляторами та версіями JDK. Він автоматично встановить Java, Scala, та збирач проєктів (sbt).

### Для Linux / macOS:
Відкрийте термінал і виконайте команду встановлення:
```bash
curl -fL https://github.com/coursier/coursier/releases/latest/download/cs-x86_64-pc-linux.gz | gzip -d > cs && chmod +x cs && ./cs setup
```
*(Для macOS з Homebrew простіше виконати: `brew install coursier/formulas/coursier && cs setup`)*

### Для Windows:
Рекомендується використовувати **WSL2** (Windows Subsystem for Linux) і працювати як у Linux. 
Якщо ж ви працюєте в нативному Windows, завантажте та запустіть інсталятор з [офіційного сайту Coursier](https://get-coursier.io/docs/cli-installation).

### Перевірка встановлення:
Після завершення `cs setup` інструменти встановлюються у вашу локальну папку (зазвичай `~/.local/share/coursier/bin`). Щоб система їх побачила, вам потрібно оновити змінні середовища. 

Виконайте в терміналі:
```bash
source ~/.profile
# або, якщо ви використовуєте bash:
source ~/.bashrc
```
*(Якщо це не допомогло, спробуйте повністю закрити термінал і відкрити його наново).*

Після цього перевірте версії:
```bash
java -version   # Має бути 21 або вище (наприклад, Eclipse Temurin)
scala -version  # Має бути 3.x
sbt --version   # Версія Scala Build Tool
```

## 2. Docker та Docker Compose

У функціональному та реактивному програмуванні ми регулярно маємо справу з мікросервісами, базами даних та брокерами повідомлень (наприклад, Kafka). **Docker** — це безальтернативний індустріальний стандарт для їх швидкого розгортання.

- **Windows / macOS:** Встановіть [Docker Desktop](https://www.docker.com/products/docker-desktop/).
- **Linux:** Встановіть `docker` та плагін `docker-compose-plugin` через менеджер пакетів вашого дистрибутива. Обов'язково [додайте свого користувача до групи docker](https://docs.docker.com/engine/install/linux-postinstall/).

### Перевірка:
```bash
docker --version
docker compose version
```
*(Переконайтеся, що Docker-демон запущений, виконавши `docker ps`)*.

## 5. Перший проєкт (Hello World)

Щоб переконатися, що все налаштовано правильно, створимо найпростіший проєкт. Ми будемо використовувати **sbt** — стандарт індустрії.

1. Створіть нову папку для проєкту та перейдіть у неї:
```bash
mkdir hello-scala
cd hello-scala
```

2. Створіть файл `build.sbt` (це конфігурація проєкту) та вкажіть версію Scala:
```scala
scalaVersion := "3.3.3"
```

3. Створіть файл з кодом програми (можна покласти просто в корінь папки, sbt його знайде) з назвою `Main.scala`:
```scala
@main def hello() = println("Hello, Functional World!")
```

4. Запустіть проєкт командою:
```bash
sbt run
```
*При першому запуску sbt завантажить необхідні бібліотеки, це може зайняти хвилину. Наступні запуски будуть миттєвими.*

Якщо в консолі з'явилося **Hello, Functional World!** — вітаю, ваше індустріальне середовище готове до роботи!

## 6. Щойно відбулася магія. Як це працює?

Програма запустилася в один клік, але під капотом відпрацював цілий інженерний конвеєр. Давайте розберемо його, щоб ви розуміли, що саме робите.

### 1. Збирач проєктів (sbt)
У реальних проєктах сотні файлів і залежностей. **sbt** (Scala Build Tool) керує цим хаосом:
- Він знаходить ваш вихідний код.
- Завантажує потрібні бібліотеки. *(До речі, sbt повністю сумісний з інфраструктурою Maven. Під капотом він завантажує залежності з того ж самого глобального репозиторію **Maven Central**, що і Java. Вся екосистема Java вам доступна).*
- Викликає компілятор і запускає готову програму.

### 2. Рушій (JVM)
Ваш процесор не розуміє мову Scala. Процес іде у два етапи:
1. **Компіляція:** Компілятор Scala перетворює ваш текстовий код у **байт-код** (файли `.class`).
2. **Виконання:** У гру вступає **JVM (Java Virtual Machine)** — це **стекова віртуальна машина (stack-based)**, яка читає цей байт-код і виконує його на вашій операційній системі (Windows, Linux чи macOS). Сучасні реалізації (як-от HotSpot) додатково використовують JIT-компіляцію для оптимізації швидкодії на льоту. 

### 3. Анатомія Hello World (посимвольно)
У Scala 3 синтаксис позбавлено зайвого шуму, але кожен символ має чітке значення:

```scala
@main def hello() = println("Hello, Functional World!")
```

- `@main` — це **анотація** (макрос). Вона каже компілятору: *"Згенеруй навколо цієї функції весь стандартний Java-шаблон (`public static void main`), щоб JVM змогла знайти точку входу і запустити програму"*.
- `def` — ключове слово для оголошення **функції** (від слова *define*).
- `hello()` — **назва** функції. Пусті дужки `()` означають, що функція не приймає жодних вхідних аргументів.
- `=` — знак **дорівнює**. У функціональному програмуванні це фундаментальна річ! Це означає, що функція — це не просто список команд для виконання, а **математичний вираз**, який обчислюється і повертає певне значення.
- `println("...")` — виклик стандартної функції виводу рядка (*print line*) у термінал.
