## 1. Встановлення Java (JDK 21+) та Scala

Сучасна екосистема Scala використовує інструмент **Coursier** (`cs`) для керування залежностями, компіляторами та версіями JDK. Він автоматично встановить Java, Scala, та збирач проєктів (sbt).

### Для Linux / macOS:
Відкрийте термінал і виконайте команду встановлення:
```bash
curl -fL https://github.com/coursier/coursier/releases/latest/download/cs-x86_64-pc-linux.gz | gzip -d > cs && chmod +x cs && ./cs setup
```
*(Для macOS з Homebrew простіше виконати: `brew install coursier/formulas/coursier && cs setup`)*

### Для Windows:
Рекомендується використовувати **WSL2** (Windows Subsystem for Linux) і працювати як у Linux.  
Якщо ж ви працюєте в нативному Windows, завантажте та запустіть інсталятор з [офіційного сайту Coursier](https://get-coursier.io/docs/cli-installation).

### Перевірка встановлення:
Після завершення `cs setup` інструменти встановлюються у вашу локальну папку (зазвичай `~/.local/share/coursier/bin`). Щоб система їх побачила, оновіть змінні середовища:

```bash
source ~/.profile
# або, якщо ви використовуєте bash:
source ~/.bashrc
```
*(Якщо це не допомогло, спробуйте повністю закрити термінал і відкрити його наново).*

Після цього перевірте версії:
```bash
java -version   # Має бути 21 або вище (наприклад, Eclipse Temurin)
scala -version  # Має бути 3.x
sbt --version   # Версія Scala Build Tool
```

## 2. Git та GitHub

Система контролю версій — це ваша інженерна гігієна. Усі завдання в курсі здаються через надання посилання на ваш публічний (або розшарений викладачу) репозиторій на GitHub, де виконано завдання.

1. Зареєструйтеся на [GitHub](https://github.com/).
2. Встановіть Git:
   - Windows: [Git for Windows](https://gitforwindows.org/)
   - Linux: `sudo apt install git`
   - macOS: `brew install git`
3. Налаштуйте своє ім'я та пошту:
```bash
git config --global user.name "Ваше Ім'я (латиницею)"
git config --global user.email "ваш.email@example.com"
```

## 4. Перший проєкт (Hello World)

Щоб переконатися, що все налаштовано правильно, створимо найпростіший проєкт через **sbt** — стандарт індустрії.

1. Створіть нову папку для проєкту та перейдіть у неї:
```bash
mkdir hello-scala
cd hello-scala
```

2. Створіть файл `build.sbt` (це конфігурація проєкту) та вкажіть версію Scala:
```scala
scalaVersion := "3.3.3"
```

3. Створіть файл з кодом програми `Main.scala`:
```scala
@main def hello() = println("Hello, Functional World!")
```

4. Запустіть проєкт командою:
```bash
sbt run
```
*При першому запуску sbt завантажить необхідні бібліотеки (це може зайняти хвилину). Наступні запуски будуть миттєвими.*

Якщо в консолі з'явилося **Hello, Functional World!** — вітаємо, ваше середовище повністю готове до роботи!

## 5. Щойно відбулася магія. Як це працює?

Програма запустилася в одну команду, але під капотом відпрацював цілий інженерний конвеєр:

### 1. Збирач проєктів (sbt)
У реальних проєктах сотні файлів і залежностей. **sbt** (Scala Build Tool) керує цим хаосом:
- Він знаходить ваш вихідний код.
- Завантажує потрібні бібліотеки. *(До речі, sbt повністю сумісний з інфраструктурою Maven і завантажує залежності з глобального репозиторію **Maven Central** — уся екосистема Java у вашому розпорядженні).*
- Викликає компілятор і запускає готову програму.

### 2. Рушій (JVM)
Ваш процесор не розуміє мову Scala напряму. Процес іде у два етапи:
1. **Компіляція:** Компілятор Scala перетворює текстовий код у **байт-код** (файли `.class`).
2. **Виконання:** У гру вступає **JVM (Java Virtual Machine)** — це **стекова віртуальна машина (stack-based)**, яка читає байт-код і виконує його на вашій ОС (Linux, macOS, Windows). Сучасні JVM (HotSpot) використовують JIT-компіляцію для оптимізації швидкодії в машинний код на льоту.

### 3. Анатомія Hello World (посимвольно)
У Scala 3 синтаксис позбавлено зайвого шуму, але кожен символ має чітке значення:

```scala
@main def hello() = println("Hello, Functional World!")
```

- `@main` — це **анотація** (макрос). Вона вказує компілятору: *«Згенеруй навколо цієї функції стандартний Java-шаблон (`public static void main`), щоб JVM змогла знайти точку входу і запустити програму»*.
- `def` — ключове слово для оголошення **функції** (від слова *define*).
- `hello()` — **назва** функції. Порожні дужки `()` означають, що функція не приймає вхідних аргументів.
- `=` — знак **дорівнює**. У функціональному програмуванні це фундаментальна річ! Функція — це не просто список імперативних інструкцій для процесора, а **математичний вираз**, який обчислюється і повертає значення.
- `println("...")` — виклик стандартної функції виводу рядка (*print line*) у термінал.
